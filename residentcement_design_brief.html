# ResidentCement Project — UI/UX Overview ## 1. Project Structure The project is a monorepo with four main applications: - **admin-dashboard**: Internal ERP for managing customers, inventory, logistics, orders, payments, production, and quality. - **corporate-website**: Public-facing marketing site with about, careers, products, and sustainability sections. - **distributor-portal**: B2B ordering platform with cart, invoicing, and payment management. - **sales-rep-app**: Mobile PWA for field sales reps to manage customers on the go. ## 2. Brand Colors & Styling ### Corporate Website (Professional & Trustworthy) - **Primary:** #0052CC (brand-primary) - **Secondary:** #0747A6 (brand-secondary) - **Accent:** #FFAB00 (brand-accent) - **Text/Headers:** #172B4D (brand-dark) - **Backgrounds:** #F4F5F7 (brand-light) - **Typography:** Poppins (Display), Inter (Body) ### Distributor Portal (Premium & Exclusive) - **Primary:** #1C1917 (brand-primary - Dark) - **Secondary/Gold:** #C5A55A (brand-secondary/gold) - **Accent:** #B8963E (brand-accent) - **Typography:** Playfair (Display), Inter (Body) ### Shared Cement Grayscale A range from #FAFBFC (50) to #172B4D (900). ## 3. Key Design Patterns - **Responsive:** Mobile-first using Tailwind. - **Glassmorphism:** Navigation headers with `backdrop-blur-md`. - **Animations:** Custom fade-in and slide-up transitions. - **Shadows:** Soft, card-based elevation. - **Icons:** Lucide React library.
